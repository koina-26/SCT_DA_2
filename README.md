# SCT_DA_2
🧹 Data Cleaning and Preparation using Python & Pandas

 📌 Project Overview

This project focuses on cleaning and preparing the Global Superstore Dataset using Python and the Pandas library.
The main goal of this project is to make raw data clean, organized, and ready for analysis by:
- Handling missing values
- Removing duplicate rows
- Converting data types
- Cleaning column names
- Exporting the cleaned dataset

This project helps in understanding the basic and important steps of data preprocessing used in Data Analytics and Data Science.

🚀 Features

✅ Load dataset using Pandas  
✅ Explore dataset structure and missing values  
✅ Handle missing data using `fillna()` and `dropna()`  
✅ Remove duplicate records  
✅ Convert date columns into datetime format  
✅ Convert numeric columns into the proper numeric type  
✅ Clean and standardize column names  
✅ Export cleaned dataset as CSV file  
✅ Beginner-friendly project structure
